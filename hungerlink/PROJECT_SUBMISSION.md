# HungerLink — Project Submission Notes

## Project
HungerLink — Smart Food Rescue & Redistribution Platform

## What to demonstrate
1. User signup/login using the demo OTP flow.
2. Role-based dashboard/features.
3. Creating a food donation.
4. AI-assisted shelf-life and priority estimation.
5. Volunteer pickup/delivery workflow.
6. Farmer produce listing and order workflow.
7. Community hunger-needs reporting.
8. Platform statistics.

## Technologies
Node.js, Express.js, MongoDB, Mongoose, HTML/CSS/JavaScript, JWT, OTP, bcryptjs.

## Important
This submission package does not contain the original `.env` file or `node_modules`. Create `.env` from `.env.example` before running the application locally.
